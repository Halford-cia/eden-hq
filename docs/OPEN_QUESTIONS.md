# Open questions for Hank

The workspace split, four owners, Google-only sign-in, financial privacy and v1 scope are settled in [the specification](SPEC.md). These inputs can arrive as their stage approaches. Keep account addresses, the build plan and real property names in private setup records.

| When | Input needed from Hank | Working default in the spec |
| --- | --- | --- |
| Stage 1 setup | Which verified Google accounts correspond to the four owners and the cleaning manager? Which accounts, if any, should be added next? | Provision only identities Hank confirms, through his private roster and `roster:apply`. Give the four owners both workspaces and the manager membership in Stay Eden only. |
| Stage 1 setup | Which Supabase organization/region, Netlify site hostname and Google Cloud project and region will Hank use? | Use Hank-controlled infrastructure, with the same Google Cloud project for the OAuth client and the backup job. Copy the actual URLs into the OAuth settings during setup. |
| First project | What project name, tasks, trades and dates from the rough plan should Hank enter first? | Start empty, allow unassigned/undated work and enter the plan by hand. |
| Before live data | Besides Hank, should one other owner of both workspaces hold a copy of the backup decryption key? Does Hank want a status-only backup monitor, and who? Do the proposed recovery targets meet the family’s needs? | Hank alone holds the key and every permission that can read data outside the app. No status monitor. The hosted Google Cloud backup job in the spec, daily self-contained sets at 09:00 UTC (03:00 or 04:00 in Chicago), 30 days’ retention, at most 24 hours of data loss, recovery within one business day, quarterly restore drill. Only a current owner of both workspaces may ever hold the key or open a restored copy; a monitor sees status only. |
| Stage 2 | Which nonproduction Netlify site hostname should the cutover rehearsal use? After a real cutover, how long should the former project stay (closed, keys removed) before Hank deletes it? | A separate nonproduction site, second OAuth client and two rehearsal Supabase projects holding synthetic data, all torn down after the rehearsal. Keep a former project closed until Hank decides it is no longer needed, then delete it. |
| Stage 2 | Which category labels does Hank want in the first build? | Start with manually entered categories and put blank categories under Uncategorized. Use USD cents. Show variance on tasks with both amounts and display coverage counts. |
| Stage 4 | What property display names and calendar time zone should the manager see? | One project per property. Use America/Chicago for the pilot until Hank supplies the workspace time zone. |
